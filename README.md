# Инструкция по установке и настройке Python

В данном руководстве описан процесс корректной установки интерпретатора **Python 3.12.6** с официального сайта и подготовка рабочего окружения.

---

## 1. Загрузка Python 3.12.6

> [!IMPORTANT]
> Для стабильной работы проекта рекомендуется использовать именно версию **Python 3.12.6**, скачанную напрямую с официального сайта [python.org](https://www.python.org/).

1. Перейдите на официальную страницу загрузки версии 3.12.6:  
   👉 **[Python 3.12.6 Release Page](https://www.python.org/downloads/release/python-3126/)**
2. Прокрутите страницу вниз до раздела **Files**.
3. Выберите установщик для вашей операционной системы:
   - Для 64-битной Windows: **Windows installer (64-bit)**.

---

## 2. Процесс установки (Windows)

1. Запустите скачанный файл (например, `python-3.12.6-amd64.exe`).
2. **Обязательно** установите галочку внизу окна:
   - ☑ **Add python.exe to PATH** *(Добавить Python в системные переменные PATH)*.
3. Нажмите **Install Now** (или выберите *Customize installation*, если требуется изменить путь установки).
4. Дождитесь завершения установки и нажмите **Close**.

---

## 3. Проверка установки

Откройте командную строку (`cmd`) или PowerShell и выполните:

```bash
python --version
```

Вывод должен соответствовать:
```text
Python 3.12.6
```

Также проверьте доступность менеджера пакетов `pip`:
```bash
pip --version
```
